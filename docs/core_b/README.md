## Access boundary

The earlier B1/B2/B3, V3, D3, V4–V9 and other studies retain their own recorded development-only scopes. Later Core A V2 and Core B CURRENT_PROFILE_V2 final scores have separate disclosed access events in the 2026-10-20/21 recovery. Do not read the older `final_test_access=0` statements as describing those later studies.

No raw video, source Parquet, feature tensor, checkpoint, full prediction/target array, full training output, or log is included in this public folder. These server-only artifact groups are listed in the release artifact registry.

Complete dated study summaries are listed in the [Core B experiment line index](EXPERIMENT_LINE_INDEX.md). The release-wide result and provenance indexes are in [docs/releases/server-sync-20261022T082418Z](../releases/server-sync-20261022T082418Z/RELEASE_SUMMARY.md).
