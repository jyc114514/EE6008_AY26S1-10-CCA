# Learning-process materials

The original learning directory is retained in the local course workspace and was not moved or deleted.

This public copy contains only selected short paper cards and source links. It excludes third-party paper PDFs, downloaded repositories, local QA/build assets, HTML login-state files, dataset metadata snapshots, and large artifacts.

The paper cards are reading notes, not replacements for the original papers. Before implementation, re-check the cited repository license, checkpoint terms, and dataset license from the authoritative source.
