# Project kickoff materials

The original kickoff folder is retained in the local course workspace and was not moved or deleted.

Only a public-facing summary is kept here. The original PDF and editable source were not copied because they contain meeting-specific material, local execution details, and contact/context information that should be reviewed by the whole team before public redistribution.

Key reusable decisions from the kickoff material:

- start from an existing V-JEPA-class implementation;
- run one small, inspectable dataset path first;
- separate baseline reproduction, lightweight modification, ablation, and analysis;
- distinguish raw data/server artifacts from public code and metadata;
- do not claim an experiment before it has a recorded run and verifiable output.

See docs/scope_v0.3.md for the current evidence-bounded scope.
