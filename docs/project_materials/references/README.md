# Public reference register

This repository records links and relevance instead of redistributing paper PDFs or subscription-only copies.

| Reference | Public source | Relevance |
| --- | --- | --- |
| I-JEPA, Assran et al. (2023) | arXiv:2301.08243 and github.com/facebookresearch/ijepa | Image JEPA concepts and target/context/predictor data flow. |
| V-JEPA, Bardes et al. (2024) | arXiv:2404.08471 and github.com/facebookresearch/jepa | Video latent prediction background. |
| V-JEPA 2, Assran et al. (2025) | arXiv:2506.09985 and github.com/facebookresearch/vjepa2 | Frozen representation, prediction, and action-anticipation starting point. |
| V-JEPA 2.1, Mur-Labadia et al. (2026) | arXiv:2603.14482 and github.com/facebookresearch/vjepa2 | Dense features and candidate model variant; downstream benefit is unverified. |
| Humanoid Everyday | humanoideveryday.github.io, arxiv.org/abs/2510.08807, and the Hugging Face dataset card | Candidate humanoid everyday data; revision, license, labels, and splits must be rechecked. |
| Humanoid Everyday code | github.com/physical-superintelligence-lab/Humanoid-Everyday | Robot/action schema reference; not raw data redistribution. |
| EPIC-KITCHENS-100 | epic-kitchens.github.io/2024 and github.com/epic-kitchens/epic-kitchens-100-annotations | Possible anticipation protocol/comparison reference. |
| VideoMAE v2 | github.com/OpenGVLab/VideoMAEv2 | Non-JEPA video representation baseline candidate. |

## Source discipline

- A source link does not itself grant permission to redistribute its files.
- Dataset and checkpoint licenses are separate from source-code licenses.
- Repository facts and metric claims must be tied to a fixed commit or revision when used in an experiment.
